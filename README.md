# CreativeStudio — Week 3 JavaScript Interactivity

## Files
- `index.html`: page structure and interactive controls
- `style.css`: visual styles and responsive layout
- `script.js`: mobile menu, form validation, active navigation, dynamic year, and back-to-top button
- `Week3_JavaScript_Interactivity_Report.docx`: technical report

## Run
Keep all files in the same folder and open `index.html` in a browser. Try the menu on a narrow screen and submit the contact form with invalid and valid-looking details.

Note: the contact form is a frontend demo. It does not send data to a server.
